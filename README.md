# BLEND — your mind

אתר תדמית ותפריט ל-BLEND, הדולפין 4, טירת הכרמל.

## העלאה ל-GitHub Pages
1. יוצרים repository חדש ב-GitHub (למשל `blend`).
2. מעלים את **כל התוכן של התיקייה** (לא את התיקייה עצמה): `index.html`, `assets/`, `fonts/`, `.nojekyll`.
3. Settings → Pages → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. אחרי דקה-שתיים האתר יהיה זמין בכתובת `https://<שם-משתמש>.github.io/blend/`.

## מה יש בפנים
- `index.html` — כל האתר (עיצוב, תפריט ונתונים).
- `assets/menu/` — תמונות המשקאות (גיבוי מקומי; כברירת מחדל התמונות נטענות באיכות מלאה ממערכת ההזמנות).
- `assets/brand/` — הלוגואים והטורנדו בכל הצבעים.
- `fonts/` — הפונט SKF Muffins (רישיון WEB לאתר אחד — לא להעביר הלאה).

## עדכון התפריט / מחירים
בתוך `index.html` מחפשים `var ITEMS =` — כל משקה הוא שורה עם שם, תיאור, מחיר (`v`) ותמונה.
